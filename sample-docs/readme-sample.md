# RAG (检索增强生成) 简介

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与文本生成相结合的 AI 架构。它允许大语言模型在生成回答之前，先从外部知识库中检索相关文档，从而提供更准确、更有依据的回答。

## RAG 的工作流程

1. **文档摄入**：将文档加载到系统中，进行分块处理
2. **向量化**：将文本块转换为高维向量表示
3. **存储**：将向量存储在向量数据库中
4. **检索**：当用户提问时，将问题向量化，在向量库中搜索最相关的内容
5. **生成**：将检索到的内容作为上下文，连同问题一起发送给大语言模型生成回答

## RAG 的优势

- **减少幻觉**：基于真实文档回答，而不是凭空编造
- **知识更新**：可以随时添加新文档来更新知识库
- **可追溯性**：可以指出答案来源的具体文档
- **成本效益**：比微调模型更经济实惠

## 常见的向量数据库

- Pinecone（云端）
- Weaviate（开源）
- ChromaDB（轻量级开源）
- FAISS（Facebook 开源）
- HNSW（分层可导航小世界图）
- Qdrant（Rust 实现的高性能向量数据库）

## 嵌入模型

嵌入模型将文本转换为向量表示。常见的嵌入模型包括：

- OpenAI text-embedding-ada-002
- Cohere Embed
- Sentence-BERT
- all-MiniLM-L6-v2（轻量级，适合本地部署）
- BGE 系列（中文优化）
